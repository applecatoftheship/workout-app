# migrations ディレクトリについて

このディレクトリは、`.claude/references/sql-migrations.md`（手動実行したSQLを
日付付きで記録する従来の運用）に代わる、スキーマ変更履歴の保存場所として
2026年8月23日に新設した。CLAUDE.mdの「実行済みSQLは...今後は`migrations/`
ディレクトリへの保存に切り替える予定」という記載に沿った対応。

## 初回のベースラインマイグレーションについて（未生成）

このセッションでは、既存スキーマを再現する初回マイグレーションファイル
（例: `20260823000000_init_schema.sql`）をまだ生成していない。

理由：`.claude/references/sql-migrations.md`は日付順の増分ALTER文の記録
であり、682行分をこちらで手動で読み解いてCREATE TABLE文一式に再構成すると、
本番の実スキーマとの間に見落とし・型の取り違えなどの乖離が生じるリスクが
ある。「推測で仕様を補完しない」というプロジェクトの方針上、本番DBの実態と
確実に一致する方法で生成すべきと判断した。

正しい生成方法は、`supabase link`実行後に

```
npx supabase db pull
```

を実行すること。これは本番DBを直接イントロスペクトしてマイグレーション
ファイルを自動生成するため、手動再構成より確実に正確な内容になる。

`supabase link`はSupabaseのアクセストークン入力（人間の手動認証）が
必要なため、Claude Codeからは実行していない。実行手順は
別途チャットで案内する。
